# ドキュメント

## 設計書（design/）

通常の開発で作る設計書を、このサンプルに合わせて書いたものです。実際の設計書を書くときのひな形にもなります。

| No | 文書 | 内容 |
|---|---|---|
| 01 | [要件定義書](design/01_要件定義書.md) | 背景、スコープ、機能・非機能要件、**本番化に向けて決めるべき未決事項** |
| 02 | [基本設計書](design/02_基本設計書.md) | システム構成、画面遷移、処理フロー、状態遷移、エラー・ログの方針 |
| 03 | [API設計書](design/03_API設計書.md) | エンドポイント、Webhook の署名と冪等性、ベンダーとの取り決め |
| 04 | [データ設計書](design/04_データ設計書.md) | テーブル定義、コード値、保存期間、kintone のフィールド |
| 05 | [照合ロジック設計書](design/05_照合ロジック設計書.md) | 正規化ルール、判定表、テストケース、ビジネス側との論点 |
| 06 | [セキュリティ設計書](design/06_セキュリティ設計書.md) | 脅威と対策、個人情報の流れ、ログのルール |
| 07 | [バッチ設計書](design/07_バッチ設計書.md) | kintone 同期、二重登録防止、制限値、リトライ |
| 08 | [テスト計画書](design/08_テスト計画書.md) | 自動テスト、E2E シナリオ、実機テストの観点 |

## キャッチアップ資料（catchup/）

このような構成のプロジェクトに加わるときに、短期間で必要な知識をつけるための資料です。

| No | 文書 | 内容 |
|---|---|---|
| 00 | [学習ロードマップ](catchup/00_学習ロードマップ.md) | 5日間の進め方、コードを読む順番、説明できるようにしておくこと |
| 01 | [React開発者のためのVue3入門](catchup/01_React開発者のためのVue3入門.md) | React との対応表、つまずきやすい点、Options API の読み方 |
| 02 | [FastAPI復習ガイド](catchup/02_FastAPI復習ガイド.md) | Pydantic v2、Depends、外部 API 呼び出しと Webhook 受信の型、テスト |
| 03 | [eKYCとJPKIの基礎](catchup/03_eKYCとJPKIの基礎.md) | 法改正、本人確認方式、JPKI の仕組み、失敗ケース、用語 |
| 04 | [kintone REST API入門](catchup/04_kintone_REST_API入門.md) | レコード操作、制限値、連携の注意点 |
| 05 | [クライゼルとGCPの基礎](catchup/05_クライゼルとGCPの基礎.md) | 製品の要点、組み合わせる構成の例、引き継ぎ時の確認リスト |
| 06 | [演習課題](catchup/06_演習課題.md) | 初級〜上級の課題と、AI ツールで進めるときのレビュー観点 |

## 読む順番のおすすめ

1. [学習ロードマップ](catchup/00_学習ロードマップ.md) で全体の進め方を見る
2. サンプルを動かしてから [基本設計書](design/02_基本設計書.md) を読む
3. あとはロードマップに沿って進める
